# Mi Cuento Breve

Este proyecto es una colección de relatos breves autoconclusivos, centrados en temas de melancolía y esperanza. Cada historia se desarrolla siguiendo estrictas normas constitucionales: frases cortas, lenguaje castellano puro y una carga sensorial intensa.

## Estructura del Proyecto

```text
src/
└── cuento/              # Relatos breves finalizados
specs/
└── [id]-[feature]/      # Especificaciones y planes de cada relato
```

## Constitución del Proyecto
El proyecto se rige por la "Constitución de Mi Cuento Breve", la cual dicta:
- **Tono Dual**: Equilibrio entre melancolía y esperanza.
- **Estructura**: Frases cortas y directas.
- **Brevedad**: Relatos de hasta 5000 palabras.
- **Sensorialidad**: Prioridad en descripciones táctiles, visuales y sonoras.

## Funcionalidades Implementadas
1. **El Robot y la Flor Eterna**: Un robot descubre la vida en un planeta abandonado.
2. **Magia, Hechizos y Pociones**: Introducción de un sistema de magia sutil y poética ligado a un cactus único.

## Desarrollo
Cada funcionalidad se desarrolla siguiendo un ciclo de:
1. **Especificación** (`/speckit.specify`)
2. **Clarificación** (`/speckit.clarify`)
3. **Planificación** (`/speckit.plan`)
4. **Implementación** (`/speckit.implement`)
